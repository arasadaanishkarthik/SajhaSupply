## 📖 About SajhaSupply

Rural shopkeepers face high purchase prices and prohibitive logistics fees because they lack individual bargaining power with manufacturers and large distributors.

**SajhaSupply** connects neighboring villages and rural Kirana shopkeepers so they can pool their product requirements into high-volume collective orders. By aggregating demand across village clusters, SajhaSupply unlocks wholesale manufacturer pricing tiers, eliminates intermediary distributor markups, and optimizes delivery routes.

---

## ✨ Key Features

1. **Futuristic 3D Collective Purchasing Simulator**
   - Interactive 3D village network visualization using Three.js / React Three Fiber.
   - Five connected village nodes (Rampur, Shivpur, Anandpur, Lakshmipur, Devgaon) dynamically pooling orders to unlock bulk pricing tiers.
   - Real-time collective savings calculations and interactive 3D product showcase.

2. **Full-Width Moving Photographic Hero**
   - Continuous, smooth photographic slideshow showcasing wholesale farm produce, grains, fruits, and warehouse logistics.

3. **Problem & Solution Interactive Glassmorphism Cards**
   - High-contrast visual cards with hover-reveal breakdown of rural retail challenges and collective volume benefits.

4. **Multi-Role Dashboards**
   - **Shopkeeper Dashboard**: Catalog browsing, 1-click group ordering, delivery tracking, and wallet.
   - **Supplier Dashboard**: Bulk demand orders, price tier management, and batch dispatch.
   - **Delivery / Logistics Dashboard**: Route clustering, load optimization, and real-time status updates.
   - **Admin Command Center**: Village cluster health, procurement analytics, and platform governance.

5. **AI Demand Forecasting & Price Optimization**
   - Seasonal demand predictions to eliminate stockouts during festivals and peak seasons.
   - Cluster route optimization reducing transit freight expenses by 40–60%.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/arasadaanishkarthik/SajhaSupply.git

# Navigate to project directory
cd SajhaSupply

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
```
